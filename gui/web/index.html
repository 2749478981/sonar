nbnk 制作
说明 / 转换环境

把游戏里的某个音效换成你自己的声音：导入 nbnk → 找到要换的那条 → 选音频 （wav / mp3 / ogg / flac）→ 转换并导出 → 把生成的 nbnk 放进 nativePC\sound\wwise\Windows\ 后生效（可直接用「导出到游戏目录」）。 只写新文件到输出目录，不会改动游戏原文件。

生效提示（重要）：武器音效的 nbnk 改完后，一般只要在游戏里切换一次武器种类、再切回来 就会重新加载，不需要重启游戏；如果这样没生效，再考虑重启游戏。
